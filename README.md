# منصة مساق التنفيذ الجبري

منصة عربية مستقلة في المستودع `yassinech832-max/execution-law-course`.

الرابط: https://yassinech832-max.github.io/execution-law-course/

## المادة والوحدات

المصدر هو ملف «الوجيز في قانون التنفيذ الجبري» لأ.د. أحمد خليل المقدم في المشروع. يحتفظ القارئ بجميع فقراته الـ1920 بترتيبها، بما فيها المراجع والفهرس. وُحِّدت المسافات البيضاء عند الاستخراج السابق؛ لم تُختصر الفقرات أو تُعد صياغة نص المؤلف.

المحاضرات الأساسية: السند التنفيذي وشروط الحق، الصيغة والصورة التنفيذية، محل التنفيذ، حجز ما للمدين لدى الغير، البيع الجبري. موضوعا القراءتين السادسة والسابعة مقترحان: مقدمات التنفيذ والحجز التحفظي، وتوزيع حصيلة التنفيذ. توجد قراءة توسعية لطرق الإجبار ومنازعات التنفيذ.

تحتوي كل وحدة على أهداف تعلم مقترحة، ومحاور تحليل، وروابط مباشرة إلى مواضع المصدر، وثلاثة أسئلة للتأمل والمناقشة. لا توجد مفاتيح إجابة أو درجات أو بوابة اجتياز. دفتر القراءة يحفظ الملاحظات في متصفح الطالب فقط.

تنتج الفيديوهات مسبقاً بمدة مقاسة قدرها 20:00 دقيقة لكل ملف. يعرض `video-manifest.js` الملفات التي اجتازت الإنتاج والمراجعة وأتيحت للطلاب فقط. لكل فيديو ترجمة عربية ونص مكتوب وفصول زمنية. الإحالات التشريعية محفوظة في سياق الكتاب؛ لا تدعي هذه النسخة تحديثها إلى التشريع النافذ. تفاصيل الإنتاج والتحقق في `video-production/README.md`.

## التشغيل والتحقق

موقع ثابت بلا مفاتيح أو خدمات خارجية. انشر محتويات الجذر عبر GitHub Pages، أو شغّل `python -m http.server 8765` محلياً وافتح `http://localhost:8765/`.

شغّل `node tests/check_course.cjs` للتحقق من حدود الإحالات وتغطية المتن ومطابقة بصمة النص. اختبار المتصفح الاختياري: `node tests/browser.cjs`؛ يتطلب Playwright وChromium وخادماً محلياً، ويمكن تحديد عنوانه بمتغير `COURSE_TEST_URL`.

لإعادة بناء فهرس المصدر: `python tools/build_source.py`، مع حزمة `python-docx` والملف الأصلي في مجلد `upload` المجاور للمشروع. يفشل البناء إذا اختلف النص الأصلي عن أجزاء المادة المنشورة. تسجل `book-index.js` بصمتي ملف المصدر ونصه.

## التحرير

`course-data.js` يحدد الوحدات وحدود قراءاتها. مواضع المصدر تبدأ من 1، وتمثل فقرات النسخة الإلكترونية، لا صفحات Word. `book-index.js` يحدد عناوين المصدر وبنيته. `material-01.js` إلى `material-06.js` تحتوي النص الكامل؛ لا تُعدّل لمعالجة صياغة تعليمية في الوحدة.

تعديل هذه المنصة لا يتطلب أي تغيير في مستودع المختبر السابق.
